## 2. 가설 2 판정 (증강기 이식 성공률 기반 원본 선별)
- 조건: filt70_1000(이식 성공률 30% 미만 8개 제외) vs rand70_1000(임의 8개 제외) vs multi78_1000(전체).
- **지지**: filt70 − rand70 ≥ 8%p(평균)이고 두 학습 seed 각각에서 filt70 > rand70이며, 파지 실패 + 파지 직후 이탈 건수가 rand70보다 적다.
- **보류**: 차이 3~8%p. 세 번째 학습 seed를 추가해 다시 본다(시간이 없으면 "방향만 관찰"로 보고).
- **기각**: 차이 ≤ 3%p 또는 filt70 ≤ rand70. 이 경우 "원본 선별 효과는 시범 수 효과와 구분되지 않는다"로 보고한다.

## 4. 조작자 다양성 vs 시범 수 분리 (multi20_1000) — 2026-11-01 13:00 취소

### 7.1 가설 3: 파지 직전 구간 과소 대표 (graspwin_1000)
- 진단 수치: 첫 그리퍼 닫기 기준 −60 ~ +20 step(−3초 ~ +1초) 구간은 Mimic 학습 데이터 538,478 step 중 81,000 step(15.0%)이고 사람 시범 78개에서도 15.3%다. 실패의 40~50%가 이 구간(파지·파지 직후 이탈)에서 난다.
- 가설: 파지 직전 구간이 학습 데이터에서 과소 대표되어 그 구간의 행동을 정확히 못 배운다. 구간 비중을 올리면 파지 관련 실패가 줄고 성공률이 오른다.
- 설계: multi78의 Mimic 1,000개는 그대로 두고, 각 시범의 파지 구간(81 step)을 잘라낸 사본을 2개씩 추가(3,000 시범, 구간 비중 15% → 34.7%). 학습 조건·epoch·batch·평가(seed 42·100회·seed 101/111·epoch 2000) 동일. 비교 기준은 multi78_1000(40.0 ± 2.0).
- 판정: 지지 = 평균 +8%p 이상이고 두 seed 모두 우세하며 파지+파지 직후 실패 건수(60) 감소. 보류 = 3~8%p. 기각 = ≤3%p 또는 역전. 생성 run 편차(±5%p 추정)가 있으므로 같은 Mimic 데이터를 쓴 이 비교가 조건 간 비교 중 가장 깨끗하다.
