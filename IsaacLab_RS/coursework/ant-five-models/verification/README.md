# 제출 저장소 실행 검증

다섯 모델을 `play_one_episode_provided.py`로 각각 실행했습니다.
seed 24, 100환경, headless 조건이며 모델 1~3은 Common-Eval,
모델 4~5는 Common-Wide-Ray-Eval task입니다. 모두 100개의 첫 에피소드 완료,
정상 종료와 가중치 SHA-256 불변을 확인했습니다.

| 모델 | 제공 evaluator 보상 평균 ± 환경 간 표준편차 |
| --- | ---: |
| 평지 | 2.795505 ± 2.174194 |
| 험지 | 8.921453 ± 5.302142 |
| 커리큘럼 | 6.320480 ± 3.605672 |
| 커리큘럼 + RayCaster | 10.959478 ± 10.460613 |
| Recovery 2800 | 11.648838 ± 11.129999 |

실행 명령과 단계 수는 `provided/results.json`, 원시 출력은 `provided/*.log`에 있습니다.
수업 제공 evaluator는 시작 관측을 `get_observations()`로 얻습니다.
PPT 공통 evaluator는 runner 생성 후 seed를 다시 설정하고 `reset()`합니다.
따라서 두 실행의 수치를 같은 평가 기록으로 취급하지 않습니다.
PPT에 사용한 기존 평가 파일과 수치는 별도로 보존했습니다.

검증 환경은 기존에 Isaac Sim과 의존성이 설치된 Ubuntu 22.04 / NVIDIA RTX 3090입니다.
새 PC의 드라이버와 Isaac Sim 전체 설치를 검증한 것은 아닙니다.

## Git 복제본 공통 평가

제출 코드 커밋을 `git clone --no-local`로 새 디렉터리에 복제하고, 전체 파일 해시를 확인한 뒤 그 복제본의 소스로 공통 평가를 실행했습니다. 다섯 모델 모두 첫 에피소드 100개를 완료했습니다. 설정·지형 mesh·초기 상태 해시는 모델 간 일치하며 공유된 PPT 평가 기록의 해시와도 일치합니다. 모델 파일은 실행 전후 동일합니다.

| 모델 | 복제본 보상 평균 ± 표준편차 | 접지 최대 전진 거리 평균 | 16초 완료 |
| --- | ---: | ---: | ---: |
| 1_flat | 2.710672 ± 2.395863 | 1.468213 m | 30/100 |
| 2_hard | 8.662973 ± 4.470968 | 3.380335 m | 20/100 |
| 3_curriculum | 6.471337 ± 4.242622 | 3.467876 m | 24/100 |
| 4_curriculum_ray | 11.170907 ± 11.151948 | 7.571260 m | 37/100 |
| 5_recovery | 11.177984 ± 11.164669 | 7.445333 m | 32/100 |

원자료는 `common-clone/`, 전체 실행 출력은 `common-clone.log`입니다. 공유 기록과 점수가 완전히 같지는 않습니다. 같은 seed와 초기 상태 해시가 물리 시뮬레이션 결과의 비트 단위 재현을 보장하지는 않습니다. 기존 PPT 수치를 이번 결과로 교체하지 않았습니다.
